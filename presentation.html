The Collegiate Challenge

Why Campus Events Needed Innovation

Traditional university communication channels fail students and organizers alike.

❌
The Status Quo Problems
• Fragmented Notices: Events get buried across noisy WhatsApp groups, paper flyers, and discarded emails.
• Missed Deadlines: Students discover key hackathons, symposiums, or sports trials after registrations close.
• Phantom Registrations: Organizers suffer huge no-show rates from unverified spam emails.
• Zero Department Targeting: Students drown in irrelevant notifications with no filtering for their major.
✅
The Campus Events Solution
• Single Source of Truth: An interactive day-by-day calendar aggregating every club and department.
• Strict Google/Gmail Verification: Guarantees authenticated students and clean event rosters.
• Live Cloud Sync: Real-time RSVP updates, seat counters, and one-tap device calendar export.
• Smart Department Feeds: Instant filtering by Computer Science, Mechanical, Civil, Arts, and Clubs.

Security First

Strict Google Authentication & Audit Trail

Enterprise-grade security preventing bot registrations and unverified submissions.

🔒
Strict Google/Gmail RFC Rules
Symmetrically validated on both mobile client and backend:

• Domain: Must end strictly with @gmail.com.
• Length: Bounded strictly between 6 and 30 characters.
• Character Rules: Only lowercase letters, digits, and periods.
• No Consecutive Dots: .. is rejected.
• Edge Constraints: Cannot start or end with a period.

Result: Invalid, disposable, or malformed email addresses are blocked before registration.
🛡️
Email Confirmation & Audit Logs
• Email Confirmation Retained: Accounts require verification click via deep link campusevents://auth-callback.
• Status Interception: Login page automatically flags unconfirmed accounts and offers a 1-tap resend button.
• Database Audit Logs (sign_in_logs): Records user ID, login timestamp, client IP address, User-Agent, and authentication method for campus safety compliance.

Database Design

PostgreSQL Relational Schema & RLS

Granular data integrity with 6 sequential migrations on Supabase Cloud.

profiles & logs
• profiles: full_name, email, department, academic_year, college_id, last_sign_in_at, sign_in_count
• sign_in_logs: user_id, sign_in_method, ip_address, user_agent, created_at
events & taxonomy
• events: title, description, category_id, organizer_id, venue, start_date, end_date, poster_url, max_capacity
• categories: Tech, Cultural, Sports, Workshop, Seminar
actions & orgs
• registrations: user_id, event_id, status, registered_at
• saved_events: user_id, event_id, saved_at
• organizations: student councils, clubs, and societies
⚡ Automated PostgreSQL Trigger: on_auth_user_created
When a user signs up, a database trigger executes public.handle_auth_user_created() to extract department, academic year, and college ID from metadata directly into public.profiles with zero client lag.

Deep Engineering

Critical Technical Hurdles Overcome

Tackling complex low-level issues in the build system and packaging pipeline.

1. Windows MAX_PATH (260-Char) CMake Failure
Problem: React Native New Architecture C++ paths reached 272 chars, crashing Ninja with dirty manifest loops.
Solution: Mapped virtual drive M:\, set CMAKE_OBJECT_PATH_MAX=1024, and refactored autolinked sources into local component directories.
2. C++ Linker Duplicate Symbol Resolution
Problem: rnscreens autolinking failed due to duplicate definition of rnscreens_ModuleProvider.
Solution: Isolated redundant generated codegen stubs from the compilation glob, enabling a clean 2m 8s build.
3. Android Package Signature Conflict
Problem: Android package manager blocked installation with "Something went wrong" when upgrading test builds.
Solution: Generated 2048-bit RSA production release keystore (v2+v3 verified) and documented clean legacy uninstallation.
4. Mobile Cross-Origin Download Blocking
Problem: Mobile Chrome blocked GitHub Releases 302 cross-origin redirected download URLs.
Solution: Hosted APK directly on same-origin GitHub Pages with native application/vnd.android.package-archive MIME type.
